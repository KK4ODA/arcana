Source code of programs distributed with Arcana
===============================================

Arcana itself
-------------
Arcana is free software under the GNU General Public License, version 3
or later. Its complete source code is in the GitHub release this archive
came from ("Source code" downloads) and at https://github.com/KK4ODA/arcana
under the same version tag.

kiwix-serve
-----------
The bin/<platform>/kiwix/ folders contain kiwix-serve, an unmodified
official build published by the Kiwix project (https://kiwix.org), licensed
under the GNU General Public License, version 3 or later. Arcana starts it
as a separate program and does not link to it.

Kiwix builds kiwix-serve statically with its build tool, kiwix-build, so
each kiwix-serve program contains several libraries. The complete source
code of all of them, in the exact versions shipped, together with the build
recipes and patches Kiwix used, is published next to these binaries on the
same release page as "arcana-<version>-kiwix-sources.tar". That archive
contains this file, a SHA256SUMS list, and the files named below. The
kiwix-tools source of the build for each platform is also included in this
archive's licenses/ folder.

The *_patch.zip files are the Meson build files Kiwix adds to these
libraries (from the Meson WrapDB); Kiwix's own patches are in the
kiwix-build archives under kiwixbuild/patches/.

(1) On Windows, Kiwix builds Xapian 1.4.23 from openzim/xapian-meson, a copy
    of Xapian with Meson build files (commit d3efba1, the latest on its
    main branch since August 2024).
(2) On Windows, libzim 9.4.0 builds liblzma itself, from its Meson wrap
    (subprojects/liblzma.wrap in the libzim source).
(3) kiwix-build downloads these as GitHub-generated archives of the release
    tags (zstd v1.5.5, docopt.cpp v0.6.3, Boost.Regex boost-1.86.0). The
    same tagged sources are provided here as the zstd project's release
    tarball and as snapshots of the tagged commits (docopt.cpp 42ebcec,
    Boost.Regex 4cbcd30).
(4) The Windows build ships ICU as separate DLLs (icu*74.dll), which
    kiwix-build takes from the Unicode Consortium's prebuilt
    icu4c-74_1-Win64-MSVC2022.zip; this is their source.
(5) The Linux x86_64 build runs in Kiwix's build image
    kiwix-build_ci_jammy:2025-11-05 (Ubuntu 22.04), which has glibc
    2.35-0ubuntu3.11: the upstream glibc 2.35 source plus Ubuntu's patches.
(6) The Linux arm64 build uses the aarch64-rpi3-linux-gnu cross toolchain
    1.1.0 (github.com/tttapa/docker-arm-cross-toolchain), built with
    crosstool-NG at commit f390dba; its glibc 2.31 is the upstream source
    plus the patches under packages/glibc/2.31/ in crosstool-NG.

Not included
------------
- GCC's runtime libraries (libstdc++, libgcc), linked into the Linux
  builds, are covered by the GCC Runtime Library Exception, which does
  not require their source to be distributed. They come from GCC
  11.4.0-1ubuntu1~22.04.2 (Ubuntu 22.04, x86_64) and GCC 12.5.0
  (crosstool-NG, arm64); see https://gcc.gnu.org.
- The macOS and Windows builds use the operating system's own C and C++
  libraries, which are not distributed with Arcana. On Windows, kiwix-serve
  needs the Microsoft Visual C++ runtime (VCRUNTIME140.dll, MSVCP140.dll)
  to be installed.

Where these files come from
---------------------------
scripts/fetch-kiwix-sources.sh in the Arcana source downloads every file
from the address Kiwix's recipes use (or the upstream project), and checks
each one against a pinned SHA-256 (git snapshots against a pinned commit).
Upstream locations:
  https://download.kiwix.org/release/   https://download.openzim.org/release/
  https://github.com/kiwix/kiwix-build  https://xapian.org/download
  https://launchpad.net/ubuntu/+source/glibc   https://www.gnu.org/software/libc/

If any source code for the programs distributed here cannot be obtained
from these places, open an issue at https://github.com/KK4ODA/arcana/issues.
